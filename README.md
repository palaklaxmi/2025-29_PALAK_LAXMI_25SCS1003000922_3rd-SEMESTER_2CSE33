## 📊 Project Overview

### Real-Time Stock Market Dashboard

The Real-Time Stock Market Dashboard is an interactive Python-based web application that allows users to monitor stock market information through a simple and user-friendly interface.

Users can select stocks such as Apple (AAPL) and NVIDIA (NVDA) and view current market information, historical price trends, trading volume, recent market data, and company information.

---

## ✨ Project Features

- 📈 Stock selection
- 📅 Time-period selection
- 💰 Current stock price
- 📊 Price change and percentage change
- 📉 Historical price visualization
- 📊 Trading volume visualization
- 📋 Recent market data
- 🏢 Company information
- 🖥️ Interactive dashboard
